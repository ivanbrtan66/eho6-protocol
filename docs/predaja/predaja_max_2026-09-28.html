Tko ima koje ruke

Dvije staze, dva stropa

PRO

Cloud sesija

Izlaz samo preko HTTPS-a. GitHub admin, puni MCP na EU (www-data). Nema SSH-a, nema laptopa, nema Downloads.

MAX

Laptop

Lokalne datoteke, SSH root na flotu, Downloads. Tu se nastavlja rad koji traži kopiranje.

Konektori

  • Genesis-eu-full: exec, write, restart, query_db. Puna moć, veća površina rizika.
  • Genesis_EU_read-only: nije autoriziran. Treba ga odobriti u claude.ai → Settings → Connectors.
  • Preporuka: pregled ide preko read-only konektora, a full se koristi samo svjesno.
install.sh · nije mijenjano

Tri rupe u dozvolama

L149 · ključ kratko čitljiv

Ključ se zapiše pa tek onda dobije chmod 600, pa između postoji prozor s 644. Popravak: umask 077 prije generiranja i chmod 700 na ~/.eho6.

~L300 · predvidljiv /tmp

/tmp/_eho6_w3id se može unaprijed podmetnuti ili zamijeniti symlinkom. Popravak: mktemp unutar $EHO6_DIR.

L374 · servis kao root

systemd jedinica nema User=, pa mrežni daemon radi kao root. Popravak: korisnik eho6, NoNewPrivileges, ProtectSystem=strict.

Jednom na laptopu

Kako MAX dobiva Downloads

Instaliraj Claude Code (Windows: irm https://claude.ai/install.ps1 | iex · macOS/Linux: curl -fsSL https://claude.ai/install.sh | bash), zatim:

cd ~/Downloads
claude remote-control

Cijeli Downloads ne ide na GitHub: u njemu su osobni dokumenti i ključevi, a GitHub odbija datoteke veće od 100 MB.
